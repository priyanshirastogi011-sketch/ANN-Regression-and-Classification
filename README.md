# ANN Regression and Classification

This project contains two Artificial Neural Network implementations built using PyTorch.

## Projects

### 1. ANN Regression
A neural network regression model trained on the Power Plant dataset to predict the target output.

### 2. ANN Classification
A neural network classification model trained on the Date Fruit dataset to classify different types of dates.

## Technologies Used

- Python
- PyTorch
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Models

- Artificial Neural Network (ANN)
- PyTorch
- Data preprocessing and feature scaling
- Train/Test split
- Model evaluation

## Dataset

- Power Plant Dataset
- Date Fruit Dataset

## Results

The classification model achieved approximately **95% test accuracy** on the test set.
